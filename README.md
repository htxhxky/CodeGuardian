# 🛡️ CodeGuardian

**Multi-Agent Code Security Audit & Auto-Fix System**

CodeGuardian is an AI-powered security auditing pipeline that uses multiple collaborating agents to **scan, reason, fix, and verify** vulnerabilities in your codebase — fully automated, end-to-end.

```
📦 Repo URL
    ↓
🔍 Scanner Agent   →  Detects vulnerabilities (SQLi, XSS, secrets, IDOR...)
    ↓
🧠 Reasoner Agent  →  Long-chain reasoning: context, severity, attack paths
    ↓
🔧 Fixer Agent     →  Generates context-aware patch PRs
    ↓
✅ Verifier Agent  →  Runs tests, validates fixes, closes the loop
    ↓
📊 Report + PR
```

---

## ✨ Features

- 🤖 **4-Agent Pipeline**: Scanner → Reasoner → Fixer → Verifier
- 🔗 **Long-chain reasoning** for deep vulnerability analysis
- 🔄 **GitHub PR integration** — auto-submits patches
- 📋 **Structured JSON reports** with CVSS-style scoring
- 🐍 Supports Python codebases (JS/TS support coming)
- 💡 Works on local folders or remote GitHub repos

## 🚀 Quickstart

```bash
# 1. Clone this repo
git clone https://github.com/YOUR_USERNAME/CodeGuardian.git
cd CodeGuardian

# 2. Install dependencies
pip install -r requirements.txt

# 3. Set your API key
export ANTHROPIC_API_KEY=your_key_here
# Optional: for GitHub PR auto-submission
export GITHUB_TOKEN=your_github_token

# 4. Run on a target project
python main.py --path ./your_project
# or scan a GitHub repo
python main.py --repo https://github.com/user/repo
```

## 🧠 Architecture — Multi-Agent Collaboration

Each agent is independent and communicates via a shared `ScanContext` object:

```
ScanContext
  ├── raw_findings      ← populated by Scanner
  ├── reasoned_issues   ← enriched by Reasoner  
  ├── patches           ← generated by Fixer
  └── verification      ← validated by Verifier
```

The Reasoner uses **multi-step chain-of-thought prompting** to evaluate:
1. Is this vulnerability actually exploitable in context?
2. What's the realistic attack path?
3. What's the blast radius if exploited?

## 📈 Token Usage

| Phase            | Avg Tokens / Run |
|------------------|-----------------|
| Scanner          | ~50K            |
| Reasoner         | ~300K           |
| Fixer            | ~400K           |
| Verifier         | ~250K           |
| **Total**        | **~1M / scan**  |

For a codebase of 50+ files with deep reasoning enabled, full pipeline runs consume ~1–2M tokens.
